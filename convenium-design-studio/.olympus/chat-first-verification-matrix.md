# Chat-First Verification Matrix

| Area | Evidence required |
|---|---|
| First use | Send first message with no project/model/budget/workflow |
| Navigation | All canonical routes, legacy redirects, invalid IDs, reload, Back/Forward |
| Data | Standalone/project chats, folders, rename/move/archive/restore/undo, migration backup |
| Chat | Clarification, brief, approach, progress, result, approvals, draft preservation |
| Constructor | Five stages, manifest sync, inspector, Apply impact, invalidation, Compare under Advanced |
| Recovery | Delayed responses, stale ownership, offline disabled actions, reconnect refresh, retry |
| Accessibility | Keyboard-only, visible focus, 200% text, 44px narrow targets, reduced motion/transparency |
| Visual | 390/820/1280/1440/1920; no overflow, clipping, overlap; Barlow and Lucide loaded |
| Runtime | `npm.cmd run check`, `/api/health`, no console/runtime/network failures |
