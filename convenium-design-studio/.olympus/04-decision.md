# Gate B decision — Convenium.Design Workbench

**Date:** 2026-08-31  
**Decision owner:** User delegated selection to the Design Director.  
**Gate B status:** Approved.

Convenium.Design Workbench is selected. It makes project-aware chat and the composer the default Work experience; systems, library resources, and mythological identity are contextual rather than competing primary surfaces.

The decision preserves a no-WebGL initial Work slice, uses CSS-only identity fallbacks until media provenance is confirmed, and permits an incremental prototype in the current application before a Tauri/React migration.
