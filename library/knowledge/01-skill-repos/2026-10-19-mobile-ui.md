## Research behind `mobile-app-shell`

- Same story, shorter journey on phones; separate phone sequences with fewer frames (Zajno OPTIKKA,
  Codrops 2025-10-16; GSAP sequence demos).
- Apple reportedly serves a single fallback image in some contexts (CSS-Tricks; third-party report).
- Scroll-linked motion only where it explains something; sticky images with copy scrolling over them;
  60 fps on a mid-range Android phone (I Like To Play, 2026).
- CSS scroll-driven animations ship in Safari 26+ (buildmvpfast, 2026).
- Meridian measurements (2026-10-18/19): a no-cache preview server downloaded every prefetched frame
  twice; `toBeVisible()` passed an opacity-0 h1; a 6 s 4G flick ran up to 154 frames behind while
  "lag after settle" passed.

## 2026-10-25 standards-floor refresh (research basis)

`mobile-app-shell` gained §0 (measure-first snippet) and §5 (2026 standards floor); the
registry description now leads with the retrofit trigger so the routing digest carries it.
Sources checked live on 2026-10-25:

- Viewport units `svh`/`lvh`/`dvh` — definitions and support (Chrome/Edge 108, Firefox 101,
  Safari 15.4): https://web.dev/blog/viewport-units
- WCAG 2.2 AA target size minimum 24×24 px (SC 2.5.8): https://www.w3.org/TR/WCAG22/#target-size-minimum
- INP as the interaction Core Web Vital (replaced FID, March 2024): https://web.dev/articles/inp
- Container queries baseline across evergreen browsers since mid-2023:
  https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries
- 2026 responsive-practice consensus — clamp() fluid type, container queries as standard,
  44 px targets with 8 px spacing, mobile-first min-width from a 360 base verified at 320:
  https://www.uxpin.com/studio/blog/responsive-design-guide/ ·
  https://tryhoverify.com/blog/responsive-design-breakpoints-2024-guide/
- Scroll-depth benchmarks conflict by vendor; no universal mobile page-length standard exists —
  the screen budget stays Apollo's own measured rule (Meridian, Oct 2026).
