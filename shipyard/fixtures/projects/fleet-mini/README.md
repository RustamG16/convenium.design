# fleet-mini

Five small sites for the "Fleet audit of five sites" live trial. Each site in `sites/` shares the same
phone defects: no viewport meta, fixed widths and a tiny tap target. A fleet pass should measure them,
port one shared shell, and bring each site to budget. A trial copies this folder to the OS temp
directory and runs there; this copy is never edited. The businesses are invented, and the addresses
use the reserved example.com domain.
