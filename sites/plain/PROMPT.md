# Brief

Build a cinematic website for me. Pick the topic yourself: read `PROFILE.md` and decide what the site is about and who it is for.

Use the media in `assets/` (see `assets/manifest.json`; every entry has a URL, a type, an aspect ratio and the prompt that made it). Be creative. Make it cinematic: motion, atmosphere, strong typography, dark and elegant, nothing generic.

Deliver a working site in this folder with a README that says how to run it.
