# project-scaffold

- Category: Engineering
- Phase: unrouted
- Status: active

- Skill ID: project-scaffold

Use at the start of any new project or major feature, before writing implementation code. Creates the context files an AI agent needs — PRD, architecture, an essentials digest, agent instructions — then scaffolds the structure before any feature work. Trigger on "new project", "start a project", "set up this repo", "before we build", "scaffold this", "greenfield", or any first request to build something that does not yet exist.
