## Quality and limitations

- Accessibility: one h1, seven h2, h3 for paths/campaigns/quests; skip link; landmarks;
  buttons with `aria-pressed`; XP figure is an `aria-live` region; focus ring brass 2px/4px
  offset with a ground halo over imagery; body contrast 15.77:1, secondary 7.49:1, brass
  8.46:1 (measured); the `moon` colour appears only in the closing line at display size.
- Performance/runtime: page code ≈ 57 KB (HTML 27, CSS 22, JS 8) plus GSAP 117 KB and four
  font files ≈ 162 KB; media is served by the CDN at source resolution (the hero poster is a
  6.2 MB PNG — see limitations). No console errors. Scroll work is GSAP scrub and a sticky
  frame only.
- Reduced motion/fallbacks: no ScrollTrigger, no load timeline; paths unpinned into
  two-column blocks; videos hidden and their posters shown via `--poster`; every element at
  its final state. Without JavaScript the page is fully readable (no `.js` class → nothing
  hidden).
- Known limitations:
  1. **Media is hot-linked from Higgsfield's CDN** at original size; if the URLs expire the page
     shows composed surface rectangles with all copy intact. To self-host, run
     `assets/download.sh`, convert to WebP/AVIF at ≤ 2560px, and replace the URLs. This is
     the one launch risk, and the only performance debt that matters.
  2. No photograph of the inhabitant exists; the "shadow self" still stands in.
  3. The quest board is illustrative; its state is `localStorage` only.
